# iCheck

iCheck 是一个 AI 模型完整性校验工具, 利用官方哈希建立可信基准并通过可信锚点实现快速验证

## 背景

从 Hugging Face, ModelScope 等平台下载 AI 模型体积巨大, 在做完整性校验时常见以下痛点

- **模型文件体积巨大**: 大型 AI 模型通常包含数百 GB 甚至 TB 级文件, 完整计算 SHA-256 需要较长时间
- **重复校验成本高**: 模型在服务器之间分发时, 每次重新计算完整 SHA-256 都会产生大量 I/O 和计算开销
- **官方校验信息分散**: Hugging Face, ModelScope 等平台提供的模型校验信息格式不同, 需要手动整理和比对
- **内网分发缺少高效的校验方式**: 内网环境中, 模型已经经过官方哈希验证后, 没有必要每次都重新执行完整 SHA-256

本项目解决的问题:

- **建立可信基准**: 首次使用官方 SHA-256 验证模型, 验证通过后建立可信基准
- **可信锚点实现快速校验**: 基于可信模型生成 `anchor_index` 和 `anchor_hash` 后续通过可信锚点快速验证模型完整性
